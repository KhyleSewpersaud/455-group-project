## Course Overview & Project Objectives
An Evolutionary Algorithm (EA) prototype developed for **CISC 455 / 851** that optimizes the placement of the 26 English letters on a standard staggered keyboard geometry. By rearranging letter positions based on English character and bigram frequencies, this project aims to minimize total finger travel distance and reduce awkward typing transitions compared to the traditional QWERTY layout.

This repository contains our working prototype, experimental results, and design documentation for the **CISC 455/851 Group Project**. In accordance with course guidelines, this project prioritizes **algorithmic design, correctness, clarity, and behavioral analysis** over extensive performance optimization.
